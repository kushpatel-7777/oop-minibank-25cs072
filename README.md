
# MiniBank

A console-based banking application developed using Java as part of the Object-Oriented Programming practicals.

## Lab 1 - Menu Shell
- Bank information using Java Record
- Menu options using Enum
- User input using Scanner
- Switch expressions
- Repeating menu until Exit

## Lab 2 - Customer and Account Classes
- Customer class with encapsulated fields
- Automatic customer ID generation
- Account class with automatic account numbers
- Constructor overloading
- Deposit and withdrawal operations
- Account balance management
- Array of Account objects

## Requirements
- Java JDK 17 or above

## How to Run

Compile:
javac *.java

Run:
java MiniBank
